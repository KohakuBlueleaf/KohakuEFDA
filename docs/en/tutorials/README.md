# Tutorials

Two walks, meant to be done in order, each in one sitting. Run the commands as you read; every step shows what the output should look like and what to read in it.

1. [First plan](first-plan.md): write a scenario, run the planner, understand machine counts, lanes and the stability findings.
2. [First layout](first-layout.md): place and route that plan inside a basement, read the rule report and the rate table, render it, open the viewer.

Guides answer focused "how do I" questions; concept pages explain why the stages are shaped the way they are; reference pages list every field. The tutorials are the bridge: one concrete factory, end to end.

## Before you start

Install the tool and fetch the dataset once: [Getting started](../guides/getting-started.md).
